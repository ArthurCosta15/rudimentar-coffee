## 📸 Sobre o projeto

O **Rudimentar Coffee** é um projeto desenvolvido para proporcionar uma experiência digital aos clientes da cafeteria, permitindo conhecer o estabelecimento, explorar o cardápio e encontrar informações importantes de maneira simples e intuitiva.

Com uma interface pensada para valorizar a identidade visual da marca, o projeto combina design, organização e usabilidade.

O cardápio conta com gerenciamento manual de produtos, facilitando a inclusão e atualização de itens diretamente no código.

---

## ✨ Funcionalidades

- 🏠 Página inicial com apresentação da cafeteria.
- ☕ Seção institucional sobre a Rudimentar Coffee.
- 📋 Cardápio organizado por categorias.
- 🔎 Filtro de produtos por categoria.
- 🖼️ Exibição de imagens dos produtos.
- 💰 Apresentação de preços em Real (R$).
- 🌿 Seção sobre a experiência da cafeteria.
- 📷 Galeria de imagens.
- 📱 Integração com Instagram.
- 📍 Seção de localização.
- 📲 Layout responsivo para dispositivos móveis e computadores.

## 💻 Executando localmente

Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

Entre na pasta do projeto:

```bash
cd rudimentar-coffee
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```
